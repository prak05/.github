# Security Policy

## Supported Releases

We actively maintain and provide security updates for all active repositories under the **@prak05** engineering ecosystem.

| Version / Tier | Supported | Notes |
| :--- | :--- | :--- |
| Flagship Core (v1.x, v2.x, v3.x) | :white_check_mark: | Active vulnerability patching and dependency monitoring |
| Lab & Academic Repositories | :white_check_mark: | Best-effort security auditing |
| Deprecated / Legacy Archives | :x: | Immutable reference snapshots |

## Reporting a Vulnerability

If you discover a security vulnerability or potential credential leak within any repository or deployment:

1. **Do not open a public issue.**
2. Send a detailed report directly to: **prakharsx05@gmail.com**
3. Include:
   - Affected repository name and commit SHA / version
   - Proof of Concept (PoC) or reproduction steps
   - Potential impact evaluation

Reports are acknowledged within 24 hours. We coordinate a coordinated disclosure timeline.
