# Contributing to PrakVerse Engineering Projects

Thank you for investing your time and talent into contributing to repositories curated by [PRAKHAR SHARMA](https://prak05.github.io/prak05/).

## Engineering Ethos

- **High-Rigor Architecture**: Code should be self-documenting, modular, and resilient under concurrency.
- **Deterministic Reliability**: We favor deterministic tests, clear type annotations, and minimal runtime overhead.
- **Privacy & Safety First**: Never commit private tokens, API keys, personal cell numbers, or unvetted credentials.

## Contribution Workflow

1. **Fork & Branch**: Create a descriptive feature branch (`feature/dynamic-crossover` or `fix/dag-cycle-detector`).
2. **Commit Hygiene**: Follow [Conventional Commits](https://www.conventionalcommits.org/):
   - `feat:` for new capabilities
   - `fix:` for bug fixes
   - `perf:` for latency/throughput optimizations
   - `docs:` for architectural or documentation updates
3. **Pull Request Protocol**:
   - Reference open issue tickets.
   - Attach test logs or benchmark validations.
   - Maintain dual-branch preservation where required.
